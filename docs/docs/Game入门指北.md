# Game组 2026春招入门指北

## 程序方向

### 入门

1. C++ 可以看 《C++ Primer Plus》，C# 可以看《Essential C# 8.0》。当作字典查询即可，主要还是锻炼自己的写代码能力，比如在这段时间用主流游戏引擎只做一个小 demo
2. 对于AI辅助编程（比如VibeCoding），需要善于使用AI辅助学习和编码；尽管如此，手敲代码的能力也要锻炼（古法编程）
3. 最好对代码编写和 Unity 编辑器有基本了解。当然 UE 或者 Godot等也可以，组内基础引擎是Unity，可以有自己的专精方向
4. 数据结构和算法（这个学习路线比较多，建议根据自己情况选择）。
5. 图形学方面如果感兴趣可以看 [GAMES101 点击蓝链进入传送门](https://www.bilibili.com/video/BV1X7411F744/)。

### 重要提示

1. 程序刚开始应当更加注重开发，在有了一定基础之后再去进行图形学/游戏物理/AI等的开发。
2. 游戏项目的成功与否不仅与程序相关，希望你能放下心来考虑**合作问题**。

一个可以参考的[学习书目](https://github.com/miloyip/game-programmer)
一个可以参考的[B站视频](https://www.bilibili.com/video/BV1PF41147Rd/)

熬测将在白天进行，预计时长为**九个小时**。
往年标准为：

1. 全部为编程实现类问题，涉及**各个方向**，需要提交代码。

## 策划方向

### 入门

1. 了解游戏策划的**类型**与**职责**，并从擅长的方向入手：比如文案方面，可以写一些游戏背景故事；数值则可以反推游戏公式，游戏数值给游戏带来的影响等；系统方面可以分析拆解一个游戏的系统组成及其带来的游戏体验。
2. 拥有较为广泛的游戏经历，以及对于一款或一个品类的游戏有较长的游戏时间与较深的游戏理解。
3. 去了解一款游戏的开发流程，以及策划在游戏开发中所起到的作用
4. 策划固然是一个比较需要创作力的岗位，但也不意味着可以完全“野路子”；读书、学习、创作与复盘都是成长路上必要的
5. 推荐阅读书籍：
   1. **《通关！游戏设计之道》（作者：（美） Scott Rogers）**
   2. 《游戏设计艺术》（作者：（美） Jesse Schell）
   3. 《游戏设计的 236 个技巧》（作者：（日）大野功二）。
6. 推荐视频主：B 站卡姐 Cara，油管 Game Maker's Toolkit
7. 推荐网站：
   1. 机核网 https://www.g-cores.com
   2. 腾讯游戏学院 http://gad.qq.com
   3. INDIENOVA https://www.indienova.com
   4. Game Developers Conference (GDC) https://www.gdconf.com/

### 重要提示

1. 对于有一定编程基础的同学，了解并学会使用基本的游戏引擎操作也是策划的加分项，可以学习团队中最常使用的Unity，按照官⽅教程和⽂档做一些简单的 demo
2. 除了需要拥有对游戏设计全貌的理解、深入机制的把握和广泛的游戏阅历等硬实力，策划在项目合作中的策划文档水平、逻辑沟通表达能力和执行效率也同样重要
3. 希望你对游戏保留有足够的热爱，这是作为游戏策划长期坚持下去的动力；当然，这个热爱最好是广泛的——只喜欢一款游戏远不足够让你成为一名真正的游戏策划
4. 对于各品类游戏，乃至于（电子）游戏的衍生物也要有所涉猎；互动视频、桌游、Arg、视觉小说等等都是可以对游戏策划有所启发的品类
5. 对于游戏企业、厂商、行业有所认知，避免自己成为一个纯粹玩游戏的，在游戏设计的路上了解业内的趋势、形式是有必要的；试着去发现游戏中优秀与失败的设计，拆解其原因，拉踩和一味地吹贬并不能让你看起来更懂游戏
6. 有美术音乐等特长也是让我们选择你的亮点，不要放弃学习，继续努力下去
7. 尝试体会优秀的游戏美术是如何与游戏主题相契合的；注重提升审美水平，对于除游戏美术之外的其他艺术形式也有了解，包括但不限于影视、编导等。

### 熬测

熬测将在白天进行，预计时长为**九个小时**。

1. 基本上都是主观题，涉及策划的**各个方向**，不感兴趣或者不会写都没关系，不用为了看上去写得多完成度高而使用 AI 工具，展现有趣的思路和完整的想法比内容数量更重要
2. 允许携带资料、上网搜索。
3. 禁止一切形式的场外协助。
